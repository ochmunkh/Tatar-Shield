# Chrome Web Store — Тайлбар (Монгол)

## Нэр
Tatar Shield — Фишингээс хамгаалагч

## Богино тайлбар (132 тэмдэгт хүртэл)
Монголын банк, төрийн сайтуудын дуураймал (фишинг) хаягийг илрүүлж, нууц үг алдахаас өмнө улаанаар анхааруулна.

## Дэлгэрэнгүй тайлбар
Tatar Shield нь Монголын хэрэглэгчдэд зориулсан хөнгөн, офлайн ажилладаг фишингээс
хамгаалах өргөтгөл юм. Бүх шалгалт таны хөтөч дотор локал хийгддэг тул ямар ч
мэдээлэл цуглуулдаггүй.

Юу хийдэг вэ:
• 🟢 Албан ёсны банк/төрийн сайтыг ногоон ✓-ээр баталгаажуулна.
• 🟡 Сэжигтэй хаягийг шар анхааруулгаар мэдэгдэнэ.
• 🔴 Хуурамч (дуураймал) хаяг дээр бүх дэлгэцийг хааж, нууц үг/OTP оруулахаас
  өмнө зогсооно.

Илрүүлдэг халдлага (v1.3.0):
• Кирилл/латин үсэг холилдсон (IDN homograph) — жишээ: кhanbank.mn (кирилл к)
• Кирилл үсгээр банкны нэрийг бичсэн — жишээ: ханбанк.мн
• Нуугдмал punycode (xn--) болон Грек/тусгай тэмдэгт — xn--khanban-v2b.mn
• Өөр TLD ашигласан — жишээ: khanbank.net (.mn → .net)
• Subdomain spoofing — жишээ: khanbank.mn.evil.com
• Үсэг сольсон (typosquat) болон нэр агуулсан (combosquat) хаяг
• Үнэгүй хостинг дээр банкны нэрийг ашигласан — жишээ: khanbank-login.netlify.app
• Домайнгүй (IP хаягтай) хуудсан дээр банкны нэр — жишээ: http://185.x.x.x/khanbank/login
• Монголын бүх банкны subdomain автоматаар хамрана (*.khanbank.mn гэх мэт)
• Төрийн бүх сайт автоматаар аюулгүй (*.gov.mn гэх мэт)

Нэмэлт: хэрэглэгч өөрөө сэжигтэй хаягийг блоклох, эсвэл найдвартай гэж
тэмдэглэх боломжтой. Бүх тохиргоо зөвхөн таны төхөөрөмж дээр хадгалагдана.
Буруу илрүүлсэн гэж үзвэл блок хуудас эсвэл popup дээрх холбоосоор Facebook Messenger-ээр мэдэгдэж болно
(өөрөө дарж нээнэ; өргөтгөл юу ч автоматаар илгээхгүй).

Нууцлал: Ямар ч мэдээлэл цуглуулдаггүй, сервер рүү илгээдэггүй, телеметргүй.
Зөвшөөрөл: `storage`, `activeTab`, мөн сайт бүрийн домайныг шалгахын тулд бүх сайт дээрх content script
(`<all_urls>`). Зөвхөн хаягийг (hostname) хөтөч дотроо шинжилнэ — хуудасны агуулгыг уншдаггүй, цуглуулдаггүй, дамжуулдаггүй.
