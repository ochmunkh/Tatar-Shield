# 🎥 Суулгах/ажиллагааны дэлгэцийн бичлэгийн заавар (Shot list)

Доорх дарааллаар ~40–60 секундын богино бичлэг хийвэл GitHub/Store-д тохиромжтой.
Дэлгэцийн бичлэгт **OBS Studio**, Windows **Xbox Game Bar (Win+G)**, эсвэл ScreenToGif
ашиглаж болно. Богино бол **GIF** (README дотор шууд тоглоно), урт бол **YouTube**.

## Дараалал (scene-үүд)

1. **GitHub-аас татах** (5 сек)
   - Repo хуудас → ногоон **Code** товч → **Download ZIP**. (эсвэл Releases-ээс zip.)
2. **Задлах** (3 сек)
   - ZIP дээр баруун товш → Extract All → `Tatar-Shield` хавтас гарч ирэхийг харуулах.
3. **Суулгах** (12 сек)
   - `chrome://extensions` бичих → баруун дээд **Developer mode** асаах →
     **Load unpacked** → задалсан хавтсыг сонгох → extension жагсаалтад нэмэгдэхийг харуулах.
4. **Icon бэхлэх (pin)** (4 сек)
   - Toolbar дээрх puzzle icon → Tatar Shield-ийн pin товчийг дарж toolbar-д гаргах.
5. **Ажиллагаа — ногоон** (8 сек)
   - `khanbank.com` нээх → icon ногоон болох, дархад "Албан ёсны сайт" гарахыг харуулах.
6. **Ажиллагаа — улаан** (10 сек)
   - Аль нэг сайт нээгээд icon дарж **"Энэ сайтыг блоклох"** → хуудас дахин ачаалагдаж
     **улаан блок хуудас** гарахыг харуулах (демо зорилгоор).
   - Эсвэл жинхэнэ дуураймал домэйн байвал шууд улаан гарахыг харуулах.
7. **Төгсгөл** (3 сек)
   - Лого + "Tatar Shield — Enkhbat.O" гэсэн бичвэр.

## GitHub-д видео оруулах 2 арга
- **GIF:** `docs/` дотор `install.gif` болгож хийгээд README-д `![](docs/install.gif)`.
- **MP4:** GitHub-ийн Issue/Release/README засварлагч дээр mp4-г чирж (drag) оруулбал
  автоматаар холбоос үүснэ. Эсвэл YouTube-д тавиад thumbnail холбоос тавих.
